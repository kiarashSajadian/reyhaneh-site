Internal reference

Design System

Structure follows Material Design 3: reference tokens, system tokens, component tokens. Use the theme button (top right) to switch between light and dark, values below update live.

Structure

refReference tokens. Raw values: palette tones, typeface, weights. Never used in components. --ref-palette-neutral-10
sysSystem tokens. Meaning: color roles per theme, typescale, shape, spacing, layout, motion, state layers. --sys-color-primary
compComponent tokens. Per component, pointing at system tokens. --comp-button-container-shape

Files: css/tokens.css (ref + sys) and css/component-tokens.css (comp). Colors come in pairs, a role and its “on” role for text and icons placed on it. Type, shape and component-internal sizes are in em. Spacing and layout are in rem. Components may only use sys and comp tokens.

Color

Each swatch shows the role, its current value, and the matching “on” role as the text color.
